# AH Premium Board

AH 股溢价率看板：自动抓取 A 股与 H 股历史行情，按每日真实汇率计算溢价率，以四宫格看板展示，支持点击进入详情大图。

## 功能

- 主页面以 2×2 网格展示多只 A+H 股的溢价率迷你走势图，点击卡片进入详情页。
- 详情页展示单只股票的完整溢价率折线图。
- 数据由 GitHub Actions 每日定时抓取，脚本按增量方式更新，只拉取上次记录之后的新数据。
- 汇率使用外汇管理局历史中间价，不使用固定近似值。
- A 股行情主源为东方财富，失败时自动切换腾讯源；港股行情主源为东方财富，失败时自动切换新浪源。
- 每只股票独立一个 JSON 文件，单只失败不影响其他股票。
- 部署在 Cloudflare Pages，通过 Git 集成自动构建。

## 项目结构

```
├── build_data.py              # 数据抓取、溢价率计算、增量更新脚本
├── config.json                # 股票配置（A/H 代码与名称）
├── index.html                 # 主页面（多卡片看板）
├── detail.html                # 详情页（单只股票大图）
├── data/
│   ├── manifest.json          # 由脚本生成的股票清单
│   ├── 601818.json            # 单只股票数据（以 A 股代码命名）
│   └── ...
└── .github/workflows/
    └── daily-update.yml       # 每日定时抓取与提交
```

## 数据格式

`config.json` 是唯一需要手动维护的配置文件：

```json
[
  {
    "label": "光大银行",
    "a_code": "601818",
    "hk_code": "06818",
    "a_name": "光大银行",
    "hk_name": "光大银行"
  }
]
```

| 字段 | 说明 |
|---|---|
| `label` | 页面显示的股票名称 |
| `a_code` | A 股代码，6 位数字 |
| `hk_code` | H 股代码，5 位数字，不足补零 |
| `a_name` | A 股名称，仅用于展示 |
| `hk_name` | H 股名称，仅用于展示 |

`data/<a_code>.json` 由脚本生成，结构如下：

```json
{
  "label": "光大银行",
  "a_code": "601818",
  "hk_code": "06818",
  "a_name": "光大银行",
  "hk_name": "光大银行",
  "updated": "2026-11-05 16:10:00",
  "data": [
    { "date": "2025-11-05", "value": 12.34 }
  ]
}
```

`value` 为当日 AH 溢价率（百分比），已按真实汇率计算完成，前端直接渲染。

## 溢价率计算方式

```
溢价率 = (A股收盘价 / (H股收盘价 × 港元兑人民币汇率) - 1) × 100%
```

- A 股与 H 股均使用前复权（`qfq`）收盘价。
- 汇率取自 `akshare` 的 `currency_boc_safe()`，即外汇管理局历史中间价。港元为直接标价法，脚本将“100 港元折合人民币”除以 100 后使用。
- A 股与 H 股按共同交易日合并，仅保留两边都有交易的日期。
- 汇率获取失败时脚本直接报错，不使用固定回退值，避免用错误汇率算出误导性结果。

## 本地运行

需要 Python 3.9+。

```bash
pip install akshare pandas
python build_data.py
```

脚本会读取 `config.json`，生成 `data/manifest.json` 及每只股票的 JSON 文件。首次运行时为全量抓取（默认近 365 天），之后每次运行只拉取上次记录之后的新数据。

## 部署到 Cloudflare Pages

1. 将仓库推送到 GitHub。
2. 在 Cloudflare Pages 中创建项目，连接该仓库。
3. 生产分支选择 `main`。
4. 构建命令填 `exit 0`，构建输出目录填 `/`。
5. 保存后 Pages 会自动部署。此后每次向 `main` 分支推送提交，都会触发重新部署。

## 定时更新

`.github/workflows/daily-update.yml` 配置了每天 UTC 08:10（北京时间 16:10）运行一次，流程为：

1. 安装依赖并运行 `build_data.py`。
2. 若生成的 JSON 中任何一只股票带有 `error` 字段，则跳过提交，保留上一次成功的数据。
3. 否则提交变更并推送，Cloudflare Pages 检测到推送后自动重新部署。

也可以在 GitHub Actions 页面手动触发（`workflow_dispatch`）。

## 已知限制

- **东方财富接口限流**：`stock_zh_a_hist` 与 `stock_hk_hist` 走东方财富 `push2` 接口，在 GitHub Actions 共享 IP 下可能被临时限流。脚本已配置腾讯源（A 股）和新浪源（港股）作为备选，但备选源的可用性同样受网络环境影响。
- **前复权价格会随除权调整**：增量更新只追加新数据，不回头修正旧数据。若某只股票发生除权，历史曲线在除权日附近可能出现轻微不连续，可手动删除该股票 JSON 后重新全量抓取。
- **汇率口径差异**：不同平台可能使用中间价、现汇买入价或现钞价，同一时点的溢价率数值会有小幅差异。本项目统一使用外汇管理局中间价。
- **A/H 名称可能不一致**：本项目不依赖名称自动匹配，A 股与 H 股的对应关系完全由 `config.json` 显式指定。
